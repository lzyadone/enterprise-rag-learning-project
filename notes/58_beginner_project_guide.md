# 零基础完整项目指南

## 目标

为第一次接触 RAG 的读者提供一份可以从头连续阅读的项目说明，避免必须在根 README、作品集文档、阶段笔记和源码之间反复跳转才能理解系统。

这份指南既解释“项目做了什么”，也解释“为什么这样设计、一次请求怎样流动、各项技术分别解决什么问题、系统有哪些边界、怎样迁移到其他数据”。

## 交付内容

- 新增 `docs/BEGINNER_PROJECT_GUIDE.md`，共 31 个主题章节。
- 从图书馆类比开始解释 RAG、Embedding、向量数据库、BM25、混合检索、RRF、Planner、重排、审计和记忆。
- 用 Mermaid 图和完整请求流程串起数据处理、索引构建、在线问答、质量检查与发布门禁。
- 解释 Ollama、本地模型、DeepSeek 和临时 OpenAI-compatible API 的定位与安全边界。
- 单独说明版本化增量索引、离线评测、qrels、holdout、安全回归和 GitHub Actions。
- 增加目录地图、运行方法、迁移指南、常见问题、术语表和推荐学习路线。
- 在根 `README.md` 和作品集入口中加入指南链接。
- 扩展作品集文档测试，检查指南存在、长度、代码围栏、相对链接和关键主题覆盖。

## 设计原则

1. 先讲生活化概念，再给准确术语。
2. 每项技术都回答“它是什么、为什么需要、在本项目哪里用”。
3. 把历史实验结果与当前默认行为分开，避免把实验模式误解为生产默认值。
4. 明确系统边界和迁移成本，不把学习项目描述成已经适合所有生产环境。
5. 所有可验证结论都链接到仓库内的代码、测试、评测或阶段记录。
